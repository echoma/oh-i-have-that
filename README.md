## 📁 项目结构

```
oh-i-have-that/
├── backend/           # 后端服务
├── frontend/          # 前端应用  
├── infrastructure/    # 基础设施代码
├── docs/             # 项目文档
└── scripts/          # 辅助脚本
```

## 🛠️ 技术栈

- **前端**: HTML5, CSS3, JavaScript
- **后端**: Go + Gin框架
- **基础设施**: Terraform + 腾讯云
- **部署**: Docker + Serverless (SCF)
- **存储**: 腾讯云对象存储 (COS)
