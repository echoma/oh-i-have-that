## 🔄 日常维护

### 应用更新流程
1. 修改代码 → 2. 重新构建 → 3. 测试环境验证 → 4. 生产环境部署

### 环境管理
- **切换环境**: `make switch-test` / `make switch-prod`
- **查看状态**: `make env-status`
- **查看日志**: 腾讯云控制台 → 云函数 → 日志查询

### 故障排除
每个步骤文档都包含对应的故障排除指南，遇到问题请查看相应步骤的troubleshooting部分。
