# 身份验证系统说明

## 📋 概述

本文档详细说明了 Oh I Have That 项目的身份验证系统实现，包括前端登录流程、后端认证服务和用户数据管理。

## 🏗️ 系统架构

### 前端组件
- **登录页面** (`frontend/src/login.html`) - 用户登录界面
- **认证管理器** (`frontend/src/assets/js/auth.js`) - 处理认证逻辑
- **登录脚本** (`frontend/src/assets/js/login.js`) - 登录页面交互逻辑

### 后端服务
- **认证服务** (`backend/auth-service/`) - 处理登录验证和token管理
- **用户数据** (`backend/auth-service/users.json`) - 存储在COS中的用户账户信息

## 🔐 身份验证流程

### 1. 页面访问检查
```javascript
// 用户访问任何页面时自动执行
authManager.initPageAuth()
```

**流程说明：**
1. 检查当前页面是否为登录页面
2. 如果是登录页面且用户已登录 → 跳转到主页
3. 如果不是登录页面且用户未登录 → 跳转到登录页面
4. 如果用户已登录 → 显示用户信息

### 2. 用户登录过程
```javascript
// 用户提交登录表单
authManager.login(email, password)
```

**流程说明：**
1. 前端收集用户邮箱和密码
2. 发送POST请求到 `/api/v1/auth/login`
3. 后端在COS中查找匹配的用户记录
4. 验证密码（SHA256哈希比较）
5. 生成JWT token并返回
6. 前端保存token到localStorage和Cookie
7. 跳转到主页面

### 3. 认证状态检查
```javascript
// 检查用户是否已登录
authManager.checkAuthStatus()
```

**流程说明：**
1. 从localStorage或Cookie获取token
2. 发送POST请求到 `/api/v1/auth/check`
3. 后端验证token有效性
4. 返回用户信息或认证失败

### 4. 用户登出
```javascript
// 用户主动登出
authManager.logout()
```

**流程说明：**
1. 发送POST请求到 `/api/v1/auth/logout`
2. 清除本地存储的token
3. 跳转到登录页面

  "password": "SHA256哈希值",

| admin@example.com | password | 管理员 | admin |
| zhangsan@example.com | secret123 | 张三 | user |
| lisi@example.com | hello456 | 李四 | user |

### 用户数据存储
- **存储位置**: 腾讯云COS对象存储
- **文件路径**: `/auth/users.json`
- **访问方式**: 通过认证服务API访问
- **安全措施**: 密码使用SHA256加密存储

## 🔧 技术实现

### 前端认证管理器 (AuthManager)
```javascript
class AuthManager {
    // 检查认证状态
    async checkAuthStatus()
    
    // 用户登录
    async login(email, password)
    
    // 用户登出
    async logout()
    
    // 认证请求
    async authenticatedFetch(url, options)
}
```

### 后端认证服务 (Go + Gin)
```go
// 主要API端点
POST /api/v1/auth/login    // 用户登录
POST /api/v1/auth/check    // 检查认证状态
POST /api/v1/auth/logout   // 用户登出
```

### Token管理
- **类型**: JWT (JSON Web Token)
- **存储**: localStorage + Cookie双重存储
- **有效期**: 7天
- **刷新**: 自动检查和刷新

## 🔒 安全考虑

### 密码安全
- 使用SHA256哈希存储密码
- 前端不存储明文密码
- 支持密码强度验证

### Token安全
- JWT签名验证
- 自动过期机制
- 安全的存储方式

### 传输安全
- HTTPS传输加密
- CORS配置
- 请求头验证
